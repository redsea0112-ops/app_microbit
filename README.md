# 마이크로비트는 움직임을 어떻게 알아낼까?

중학교 정보 · 인공지능 탐구 수업(3차시)에서 쓰는 학생용 웹 학습지입니다.

- 1차시: 가속도센서 값과 내가 정한 규칙으로 걸음 수 세기
- 2차시: CreateAI에 움직임 데이터를 학습시켜 동작 구분하기
- 3차시: 두 방법 비교하고 나만의 동작 인식 인공지능 계획하기

## 쓰는 방법

1. 맨 위에 학번과 이름을 적습니다.
2. 오늘 차시 탭을 골라 활동을 채웁니다.
3. 맨 아래 **제출하기**를 누르면 `학번_이름_N차시.txt` 파일이 내려받아집니다. 선생님이 알려 준 곳에 올려 주세요.
4. 다음 시간에 이어 쓰려면 **📂 지난 제출 파일 불러오기**로 그 파일을 다시 엽니다.

쓴 내용은 어디에도 저장되지 않습니다(서버·브라우저 저장소 모두 사용하지 않음).
