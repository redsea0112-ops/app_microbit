# 마이크로비트는 움직임을 어떻게 알아낼까?

중학교 정보 · 인공지능 탐구 수업(3차시)에서 쓰는 학생용 웹 학습지입니다.

- 1차시: 가속도 크기를 재고, 내가 정한 기준값으로 정지·걷기·뛰기 나누기
- 2차시: CreateAI에 움직임 데이터를 학습시켜 동작 구분하고, 두 방법 비교하기
- 3차시: 2차시와 같은 절차로 나만의 동작 인식 인공지능 만들기

## 쓰는 방법

1. 맨 위에 학번과 이름을 적습니다.
2. 오늘 차시 탭을 골라 활동을 채웁니다.
3. MakeCode 블록은 `Win + Shift + S`로 캡처한 뒤, 점선 상자를 누르고 `Ctrl + V`로 붙여 넣을 수 있습니다.
4. 맨 아래 **📄 제출 PDF 만들기**를 누르면 `학번_이름_N차시.pdf` 파일이 내려받아집니다. 선생님이 알려 준 곳에 올려 주세요.
5. 다음 시간에 이어 쓰려면 **📂 지난 제출 파일 불러오기**로 그 PDF를 다시 엽니다.

쓴 내용은 어디에도 저장되지 않습니다(서버·브라우저 저장소 모두 사용하지 않음).

PDF는 [jsPDF](https://github.com/parallax/jsPDF)(MIT)와 [html2canvas](https://github.com/niklasvh/html2canvas)(MIT)로 만듭니다. `vendor/` 폴더에 들어 있어 외부 인터넷 주소를 부르지 않습니다.
